Column Descriptions:

  • EQ Count (30d/7d): Number of earthquakes in the last 30/7 days
  • Max/Avg Mag: Maximum/Average magnitude in the period
  • Avg Depth: Average depth of earthquakes in kilometers
  • Days Since Last EQ/Major EQ: Days since the last earthquake/major earthquake (M≥3.0)
  • Next 7d: Predicted earthquake count and maximum magnitude for the next 7 days
  • Risk Level: Low, Medium, or High risk classification

Note: This dataset shows daily earthquake features for each province from 2018-2025, with features calculated based on historical seismic activity and labels for machine learning prediction tasks.
